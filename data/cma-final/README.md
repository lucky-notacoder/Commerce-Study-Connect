This folder contains course, chapter, and chapter-note data for CMA Final.

- `courses.js` defines the CMA Final papers and course descriptions.
- `chapters.js` lists chapters for Papers 13–19 and the three alternative Paper 20 electives.
- `chapter-details.js` provides definitions, key points, and study tips for each listed chapter.
- Update the matching subject entry, chapter list, and chapter details when changing course content.
